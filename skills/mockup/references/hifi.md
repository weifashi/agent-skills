# 高保真效果图:仿真界面、可点原型

目标:对方看完就知道「做出来长什么样、怎么一步步用」,不用再想象。零件全在 `assets/hifi.html`,打开就能照着抄;类名和用法见那一页的 S0。类名都带 `hf-` 前缀,可以和模板、积木放在同一页。

1. **先定品牌色**:在页面自己的 `<style>` 里覆盖 `:root{--hf-brand…}`(默认琥珀黄配黑)。整页只用这几种颜色。
2. **默认做成可点的**:照 `assets/hifi.html` 的 S7 写。每个端的第一屏加 `data-entry`(每个端恰好一个入口);界面上能点的地方加 `data-go="目标屏"`;每屏旁边用 `.hf-pnote` 写说明(这一屏做什么、看到什么、有什么规则、对应哪条需求)。可点原型只在屏和屏之间跳转,不发请求、不存数据。
3. **要打印或一次看完时排故事板**:整页用 `.wrap.rep`,故事板外面包 `.bleed`。一条流程一行(`.hf-flow`),屏与屏之间画箭头(箭头和后一屏一起包进 `.hf-next`),每屏下面一句「点了什么 → 看到什么」(`.hf-cap`)。分支另起一行,用 `.hf-branch` 写从哪一屏分出来,编号 3a / 3b。
4. **状态画全**:顺利的一条之外,失败、空、没权限、断网、等待中各画一屏。只画顺利路径不算完成。
5. **像真的**:状态栏、标题栏、底部标签栏、前后屏对得上的金额和时间、合适的图标;示例数据像样,但不用真实客户、手机号、证件。二维码只用示意码(`#qr-a` / `#qr-b`)。
6. **机框里只放界面上真有的字**,讲解写在 `.hf-cap` 和机框外。机框里的字号按真实 App(11~17px);机框外的说明仍 ≥16px。
7. **不抄别家**:不贴别家产品的截图、商标;要对标就单独做「对标点」表格,界面画自己的。

## 写完先跑

```bash
python3 <技能目录>/assets/hifi/inline.py <页面>
```

它把组件样式、可点原型脚本和**用到的**图标写进页面(重复跑结果不变),并检查:每屏有标题和说明、跳转目标都在、每个端恰好一个入口、每屏都能从入口点到。不合格就报错、不改页面。

之后照 SKILL.md「检查」跑溢出检查,并**截图人工看**手机、平板、电脑三种宽度。界面里有泰文等非中英文字时,截图的机器要装对应字体,否则显示成方块。
