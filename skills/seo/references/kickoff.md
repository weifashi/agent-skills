# 开工表和任务单

## 开工表

先自己查，查不到的一次问清。

| 项 | 说明 | 从哪查 |
|---|---|---|
| 项目一句话 | 是什么、给谁用 | 官网首页、README |
| 主要市场 | 国家 + 语言，按重要程度排 | 问用户；官网已有哪些语言版本 |
| 已有功能 | 只能宣传这些 | 产品、交接文档 |
| 不能宣传的功能 | 没接通、没做完、当地没有资质的 | 交接文档、问用户 |
| 竞品 | 3–5 个 | 问用户；或搜主词看前 10 名 |
| 环境 | 测试 / 正式；正式域名是否已定 | 项目规则、问用户 |
| 官网代码和发布方式 | 在哪、怎么发、能不能自己发 | 代码库、项目规则 |
| 取数工具 | DataForSEO 是否已接入、余额 | 调一次余额接口 |
| 已有数据 | 以前的关键词表、Search Console 权限 | 代码库 docs、问用户 |

拿不到 Search Console 很正常（新域名、没上线）。把它写进「缺口」，不要因此停下。

## 可以直接转发给 AI 的任务单

把方括号里的内容换成项目信息，整段发过去。

```text
请帮我给一个项目做 SEO（搜索引擎优化）。目标是：让目标国家的用户在谷歌搜相关的词时，能搜到我们对应的页面。

【项目信息】
- 项目名和一句话介绍：[填写]
- 官网地址和代码位置：[填写]
- 主要市场（国家和语言），按重要程度排：[填写]
- 产品已经有的功能（只能宣传这些）：[填写]
- 还没做好、不能宣传的功能：[填写]
- 已知的竞品：[填写，不知道就写「请你找」]
- 现在是测试环境还是正式环境，正式域名是否已定：[填写]

【可以用的工具】
- DataForSEO（已接入）：用来查搜索量、难度、谷歌前 10 名、竞品的排名词。先看余额，整轮调研的花费控制在 5 美元以内；超出前先告诉我。

【请按这个顺序做】

第一步：调研，只出报告，不改代码
1. 看官网现状：每页的标题和搜索描述、是否允许收录、各语言版本之间的互相标注（hreflang）是否指向打得开的页面、有没有网站地图。
2. 对每个目标国家，分别用当地语言查：
   - 用户会搜哪些词，每个词每月搜索量、难度、广告出价；
   - 主要的词，谷歌前 10 名现在是谁；
   - 竞品靠哪些词拿到流量，有没有我们没想到的做法。
3. 按「搜的人想要什么」筛词。排除看新闻的、查词义的、找硬件的、找某个具体品牌的词。只留和我们已有功能对得上的词。
4. 把词分成几组，一组词对应一个页面。给出每个页面的建议地址、主词、副词、标题草案。
5. 其他语言不要直译关键词，用当地人真正会搜的说法。当地没有这个概念的，就不做这一页。
6. 报告第一屏用一张表说清：主攻哪些词、不碰哪些词、各语言怎么安排、最可能证明这个判断错了的事实、下一步、什么时候该停。每个数字写明来源和日期。查不到的写「没查」，不要编。

第二步：先给我看一个页面的效果图
- 挑一个分页，套用现有官网的样式做出来给我看，并用一张表说明它和首页差在哪。我确认以后再做其他页面。

第三步：做页面
1. 分页用脚本从首页生成，脚本进代码库。首页改了，重跑脚本，分页要能跟着更新；脚本重复运行，结果必须完全一样。
2. 每个页面只承诺已有的功能。价格、免费期这类数字要和官网现有内容及产品规则一致，发现不一致先问我。
3. 一次做齐：
   - 每页的标题和搜索描述；
   - 指向本页的规范地址（canonical）；
   - 同一内容各语言版本互相标注，含默认版本；
   - 网站地图；
   - 结构化数据：软件信息和常见问题；
   - 页脚里同语言其他分页的链接。
4. 现有首页的画面不要动，只改标题、搜索描述这类搜索引擎看的内容；要动画面先问我。

第四步：发布和核对
1. 测试环境必须保持「不让搜索引擎收录」。
2. 做一个正式上线用的开关：打开后去掉「不让收录」，把页面里的地址和网站地图换成正式域名，生成 robots.txt。不打开时，结果和现在完全一样。
3. 发布前先确认线上现状和发布记录一致，不一致就停下来告诉我，不要硬发。
4. 发布后逐页确认能打开、标题正确；每个页面用电脑宽度和手机宽度各截图看一遍，检查文字有没有被截断或撑出屏幕。没检查的页面要如实说明。
5. 把「正式上线当天要做的事」写成清单放进项目规则。清单包括：打开开关、换域名、提交网站地图、接入谷歌站长后台（Search Console）、8 周后看数据、12 周后按标准决定是否继续。

【沟通要求】
- 全程用中文，像给不懂技术的老板讲。专业词第一次出现时用一句话解释。
- 每完成一步先汇报结论，再说依据。需要我决定的事单独列出来，并给出你的建议。
- 做完了、验证了什么，如实说；没验证的也如实说。
- 不要一次问我很多问题。能自己查到的先查，只问必须由我决定的事。
```

填的时候注意：

- 「已有功能」和「不能宣传的功能」两栏要认真填，这是 AI 最容易写错的地方。
- 正式域名已经定了就写明，第四步可以直接按正式环境做，不用绕「测试环境不收录」那一套。
