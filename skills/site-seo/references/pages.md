# 定页面和写页面

## 为什么一类词配一个页面

搜索引擎给一个页面排名时，主要看它在讲哪一件事。首页同时讲很多卖点，哪个词都排不靠前。搜某个词的人，最好直接落到专讲这个词的页面。

向用户解释时用一张表：

| 页面 | 搜的人想要什么 | 他们会搜的词 |
|---|---|---|
| 首页 | 找一套这类系统 | 品类主词 |
| 功能 A 页 | 只想要功能 A | 功能 A 的词 |
| 免费 / 价格页 | 先问要多少钱 | 免费、价格相关的词 |
| 行业页 | 想看自己这种店能不能用 | 行业 + 品类 |

页数不是固定的。先做搜索量够、难度低、和已有功能正好对上的 3 个左右，上线后看数据再加。

## 页面—关键词表

每个页面一行：

| 页面地址 | 主词 | 副词 | 标题草案 |
|---|---|---|---|
| `/` | 品类主词 | 2–3 个近义词 | 品牌 + 主词 — 核心卖点 |
| `/功能-a/` | 功能 A 主词 | 「怎么做」「制作」类变体 | 主词 — 两个最强卖点 |

- 地址用当地语言的词，连字符分隔，不带特殊字母（当地字母转成基本拉丁字母）。
- 一个词只归一个页面。两个页面抢同一个词会互相拖累。
- 标题 60 个字符以内放主词；描述 150 个字符左右，像一句能让人想点进来的话，不是关键词堆砌。

## 分页和首页的关系

分页不是另做落地页，是同一个官网里的子页面：样式、素材、价格区、页脚和首页一样，只换：

| 位置 | 怎么换 |
|---|---|
| 浏览器标题、搜索描述 | 换成这一页的主词和卖点 |
| 首屏小字 | 「品牌 › 本页主题」，品牌可点回首页 |
| 首屏大标题和副标题 | 围绕主词写 |
| 首屏要点 | 换成和主词相关的 3 条 |
| 步骤 / 教程段的标题 | 写成「主词 + 怎么做」，正好接住「怎么做」类搜索 |
| 中间的段落 | 只留和主词相关的，其余去掉 |
| 常见问题 | 留相关的几条，加 1–2 条搜的人最常问的（例如「和 X 类工具有什么区别」） |
| 导航 | 只留本页还有的段落 |
| 页脚 | 加同语言其它分页的链接 |

首页本身：只换标题和描述，页脚加分页链接。画面不动。

## 多语言

- 每种语言单独查词。同一个功能，各国的叫法不同，直译常常没人搜。
- 一种语言里某个概念没人搜，就不做这一页，不要为了整齐硬凑。
- 没有可靠数据的语言（例如目标人群主要用的搜索引擎不是谷歌）写进「没查」，说明这种语言的页面靠什么获客。
- 同一主题的各语言页面，地址可以不同（各用当地词），用 hreflang 互相标注即可。
- 非母语的文案，交付时提醒用户找当地人审一遍。

## 只说做得到的事

- 每个页面只承诺已有功能。「不能宣传的功能」清单里的东西，连暗示都不要有。
- 需要某项资质或对接才成立的词（税务、支付、合规类），没接通就不做。
- 价格、免费期、数量这类数字，以官网现有内容和产品规则为准；两处不一致时先问用户，不要自己选。
- 不写效果承诺（「营业额提升 X%」），只写机制。

## 先给用户看一页

铺开之前先做一个分页的效果图：

- 套用现有官网的真实样式和素材，不要另画。
- 角落放一个「效果图 · 未上线」的小标签。
- 配一张「首页现在写的 → 这个分页写的」对照表。
- 电脑和手机两种宽度自己先截图看过，再发给用户。

用户确认样子后，其余页面按同一套规则生成。
